Corrobo

Document intelligence and name screening for Indian lenders

Reads bank statements, payslips, tax returns, GST filings, IDs and bills across 56 document types, then flags what a human should check. It runs on my own fine-tuned 8B vision-language model, Corrobo-DocVL, trained on a Mac plus a small rented-GPU budget.

78% fields exact · 48 sealed real documents

I publish how the number is measured, with its sample size, because most accuracy claims in this market come with neither. A write-up of the model is submitted to a computer-vision workshop.

Code is private. Walkthrough on request.

Skimstone

Voice agent for bank fraud checks, built on Bolna

Calls a customer in Hindi, Hinglish or English to confirm a flagged UPI payment before the money leaves. It never asks for an OTP, and it hands real scam victims to a human fraud officer with a case card. Entered in Bolna's voice-AI buildathon.

Earlyman

Cost and failure tracing for teams using AI coding agents

Shows where an agent session spent its tokens, why it failed, and what to change so the same mistake doesn't happen on the next pull request. I built it to run my own work: most of my code is written by agents I direct and review.
